Es exactamente la ventana de 24h, **no un bug del CRM**. Hoy el CRM no avisa nada, el mensaje falla en silencio.

### Contexto — la "ventana de atención" de WhatsApp
WhatsApp solo deja a la empresa mandar **texto libre** durante las 24h siguientes al último mensaje **del cliente**. Cada mensaje del cliente reinicia el contador. Pasadas 24h sin que el cliente escriba, la ventana **se cierra** y solo se puede retomar con una **plantilla aprobada por Meta**. Es una regla oficial anti-spam.

### H1 — Detección de la ventana de 24h | ✅ **HECHO (2026-07-13)**
- Backend: `ConversacionDto.VentanaExpiraEn` = último inbound + 24h (batch en `GetAll`, método `GetUltimoEntrantePorConversaciones`).
- Frontend (`chat-window`): computed `ventanaCerrada` (solo WhatsApp; combina el hint del backend con los mensajes cargados en tiempo real). Si está cerrada: banner rojo + composer deshabilitado (texto, enviar, adjuntar, ubicación, emojis). Aviso amarillo con el tiempo restante en las últimas 2h. Reloj interno cada 60s para recalcular.
- **Nota:** las plantillas (H2) siguen pendientes; el banner solo avisa y bloquea, todavía no ofrece plantilla.

### H2 — Sistema de plantillas (genérico) | **L (2–4 semanas)** | BLOQUEADO
Sincronizar plantillas desde Meta, selector, formulario de variables, vista previa, envío, historial. Genérico: cualquier plantilla nueva de Meta debe funcionar sin tocar código.

**Tres bloqueos ANTES (no son código):**
1. **Go Live + App Review.** Hoy se usa el número de PRUEBA en modo Desarrollo. Las plantillas reales viven en la WABA real de GramVet; no se pueden tocar ni probar hasta pasar App Review.
2. **respond.io vs Cloud API directa.** El número real está HOY en respond.io (un número = un proveedor). Decisión de negocio del cliente: ¿saca el número hacia nuestra Cloud API, o integramos con la API de respond.io (otro desarrollo)? Define cómo se construye todo. Las plantillas del cliente están en un `asset_id` distinto al de nuestra config de prueba → hoy el CRM NO tiene acceso a ellas.
3. **Auto-mapeo de variables.** Meta entrega las variables como `{{1}}`, `{{2}}` **sin decir qué significa cada una**. El mapeo 100% automático NO es confiable: hay que configurar una vez, por plantilla, qué campo del CRM va en cada variable (o llenado asistido). Bajarle la expectativa al cliente: "genérico + asistido", no "mágico".
